Buscador de Precios Pewen — Guía de puesta en marcha

Tres partes. Se hacen una sola vez. Después queda andando solo.

A Conectar la subida de fotos (Apps Script)

Es lo que permite que cada vendedor saque o suba una foto desde el buscador y la vean todos. Sin este paso el buscador funciona igual, pero sin poder subir fotos nuevas.

  1. Entrá a script.google.com con tu cuenta y tocá Nuevo proyecto.
  2. Borrá lo que haya y pegá TODO el contenido de apps-script/Codigo.gs. Guardá (💾).
  3. Arriba a la derecha: Implementar → Nueva implementación. En el engranaje ⚙ elegí Aplicación web.
  4. Configurá:
    Ejecutar comoYo (tu cuenta)
    Quién tiene accesoCualquier persona
  5. Tocá Implementar. Te va a pedir permiso para Drive y Sheets → Permitir (si dice "no verificado", entrá por Configuración avanzada → Ir al proyecto).
  6. Copiá la URL de la aplicación web (termina en /exec). Guardala, la pegás en el paso C.
Primer uso: en el editor de Apps Script corré Ejecutar → subirFotoDePrueba y mirá el Registro (Ver → Registros). Te va a mostrar el ID de la carpeta y de la planilla que creó solo — no hace falta que hagas nada con eso, es solo para confirmar que anduvo.
Cada vez que cambies el código del script tenés que Implementar → Gestionar implementaciones → ✏️ → Nueva versión para que se aplique.

B Las fotos que ya vienen (Drive + catálogos)

Esto no requiere nada tuyo: build_catalogo.py ya le puso foto a los productos que matchean con confianza contra tu Drive. Lo que falta queda en SIN-FOTO.csv — se va completando con las fotos que suba el equipo (parte A) o corriendo el script de nuevo cuando aparezcan fotos nuevas en Drive.

C Publicar el buscador (GitHub Pages — gratis)

Queda una URL que el equipo abre desde el celu o la PC.

  1. Abrí index.html y en la línea var SCRIPT_URL = ""; pegá adentro de las comillas la URL del paso A. Guardá.
  2. En github.com creá un repositorio nuevo (sugerido: privado, es un catálogo interno con precios).
  3. Subí toda la carpeta: index.html, productos.json, la carpeta fotos/.
  4. Andá a Settings → Pages. En "Branch" elegí main y carpeta /root. Guardá.
  5. Esperá 1–2 min y vas a tener una URL tipo https://nicolaskank-arch.github.io/buscador-precios-pewen/. Esa es la que le pasás al equipo.
Si el repo queda privado, GitHub Pages con repos privados requiere un plan pago o que el que lo abre tenga acceso al repo. Si preferís que sea gratis y público, tené en cuenta que cualquiera con el link va a poder ver los precios — decime cuál preferís y ajustamos.

Hecho para Pewen · para actualizar productos: python build_catalogo.py "nueva lista.xlsx" y volver a subir los archivos.
